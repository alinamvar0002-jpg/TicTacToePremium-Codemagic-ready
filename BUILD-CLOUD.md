# Cloud APK build

This source is prepared for Codemagic. The Android project is under `tictactoe/`.

1. Push the contents of this folder to a GitHub repository.
2. In Codemagic, add the repository and select the `android-debug` workflow.
3. Start the build.
4. Download `app-debug.apk` from Artifacts.

This is a debug APK and does not require a release keystore.
